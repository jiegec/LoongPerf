# LoongPerf

LoongArch instruction-level performance data, measured on real hardware.

[Open the instruction table](table.html){ .md-button .md-button--primary }

The table lets you choose microarchitectures and instruction-set extensions,
then shows latency and throughput side by side.

## Coverage

Measurements currently cover the **LA464** and **LA664** microarchitectures,
across these LoongArch instruction-set extensions:

- **Base** — the base LoongArch scalar instruction set
- **LBT** — the LoongArch Binary Translation extensions
- **LSX** — the 128-bit vector extensions
- **LASX** — the 256-bit vector extensions
